# KU Hub

Printed models of "The Hub", a new KU building, for the building's launch event.

Michael Brock supplied the meshes. Michael is part of the building project. This repo has no source CAD files, only the meshes he sent.

## Revisions

Each folder holds one revision. The shell is split into parts that print separately.

| Folder | Contents |
|--------|----------|
| `v1/` | `20260330_KU-Print_1-30.3mf`: first print file |
| `v2/` | `The Hub shell REV_P1`–`P5` (STL) |
| `v3/` | `The Hub shell_rev3_PT_1`–`PT_4` (STL), plus 3MF print projects |
| `v4/` | `The Hub shell_rev_4_PT_1`–`PT_4` (STL), `REV_P5` (STL + 3MF) |

`v4/` is the latest revision. Its `REV_P5` part comes from `v2/`.
